# Itadaki Ramen Shop — Independent Student Concept

A responsive Japanese-inspired restaurant website concept created as part of a web development internship project.

> **Important:** This is an independent student project created for educational purposes. It is not affiliated with, commissioned by, endorsed by, or officially connected to Itadaki Ramen Shop.

## Project Overview

The project explores how a local restaurant brand can be presented through a modern digital experience combining:

- Japanese-inspired visual design
- Responsive layouts
- Restaurant menu browsing
- Category filtering
- Search
- Gallery with lightbox
- Light and dark themes
- Sakura-inspired motion
- Contact form validation
- Location and contact information
- Mobile navigation
- Accessibility considerations

## Tech Stack

- React
- JavaScript
- Vite
- Tailwind CSS
- React Router
- Lucide React
- CSS animations

## Features

### Home

- Cinematic hero section
- Japanese-inspired visual language
- Sakura animation
- Signature dishes
- Restaurant story concept
- Editorial content section
- Visit CTA

### Menu

- Category filtering
- Search
- Reusable dish cards
- Dietary/spicy/special tags
- Responsive layout

### Gallery

- Category filtering
- Responsive masonry layout
- Image lightbox
- Keyboard navigation
- Reduced-motion support

### Theme

- Light mode
- Dark mode
- System preference detection
- Theme persistence with localStorage

### Contact

- Form validation
- Accessible form states
- Success state
- Frontend-only demonstration

## Important Content Note

Restaurant-specific information such as:

- menu items

- descriptions
- opening hours

- imagery

should be verified with the business before being used for any official or production website.

## Running Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
